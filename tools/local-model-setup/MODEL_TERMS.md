The exact [Qwen tag page](https://ollama.com/library/qwen3:4b-q4_K_M) and [Ministral tag page](https://ollama.com/library/ministral-3:8b), checked on 2026-10-13, each expose an Apache 2.0 license entry. That is upstream model metadata, not a license assigned to these scripts. Before download, inspect the linked license, model card, notices and applicable use/redistribution conditions for the exact revision. Tags and package contents can change.

Use [Ollama's Windows documentation](https://docs.ollama.com/windows) for the runtime installation source and compatibility requirements. WinGet package agreements and runtime terms are separate from model terms. The explicit AcceptModelTerms switch records that the operator reviewed terms; it neither validates legal compliance nor silently accepts installer agreements.

No claim is made about guaranteed hardware support, latency, full model capabilities or compatibility with the application's provider contract. No model inference or weight download occurred during publication preparation.
